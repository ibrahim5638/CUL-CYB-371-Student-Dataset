# Student Dataset Project

## CUL-CYB 371 – Data Mining and Data Warehousing

This project contains a fictional student dataset created with Python.

### Files
- `student_dataset.py` — Python code that creates and displays the dataset.
- `student_dataset.csv` — Dataset saved in CSV format.
- `README.md` — Project description and instructions.

### Dataset fields
- Student_ID
- Department
- Level
- Attendance_Percentage
- Average_Exam_Score

### Run the Python file
Install pandas if necessary:
```bash
pip install pandas
```
Then run:
```bash
python student_dataset.py
```
